## 后续建议

### 完整训练运行
```cmd
# 使用 cevae_py36 环境
conda activate cevae_py36

# IHDP 完整训练 (10重复实验, 100轮)
python cevae_ihdp.py -dataset ihdp -reps 10 -epochs 100

# IHDP1000 合并模式
python cevae_ihdp.py -dataset ihdp1000 -epochs 100

# IHDP1000 分离模式 (100重复实验)
python cevae_ihdp.py -dataset ihdp1000 -separate_reps -n_reps 100 -epochs 100

# TWINS 数据集
python cevae_ihdp.py -dataset twins -epochs 100
```

### GPU 加速
如需使用GPU加速训练，需要:
1. 安装 NVIDIA GPU 驱动
2. 安装 CUDA Toolkit 8.0 (兼容 TF 1.2.1)
3. 安装 cuDNN 6.0
4. 安装 TensorFlow GPU 版本
